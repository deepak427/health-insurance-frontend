# Design System: Dolphin Buddy (Instagram DM Edition)

## Overview

**Creative North Star: "Direct Message Social Assistant"**

Dolphin Buddy adopts an Instagram Direct Messaging interface paradigm rather than generic single-column ChatGPT web layouts.

Key Characteristics:
- Instagram Direct Messages Inbox sidebar (conversations list, online active indicators, search bar).
- DM Chat Header: Agent Profile Avatar with "Active Now" green indicator badge and verification icon.
- Pill-shaped asymmetrical DM message bubbles (`rounded-[22px] rounded-br-[4px]`).
- Rich Instagram link card attachments for downloadable PDF Guides.
- Instagram style floating pill input bar with circular attachment buttons (`+`).
